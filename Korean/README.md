# 주타이쿤 2 한국어 패치 — 2026-10-10

기존 번역을 보완한 통합 XML 패치입니다. 기본판은 굴림(Gulim), 선택판은 Pretendard를 사용하며 두 판의 문구와 UI 수정 내용은 같습니다. 실행 파일·DLL·TTF·이미지·저장 게임·개인 설정은 배포하지 않습니다.

## 이번 변경

- 메뉴와 패널 글자가 고해상도에서 축소되는 문제를 완화하도록 `MaxFontScalingResolution`을 600에서 20000으로 복원했습니다. 그 밖의 로케일 설정과 `disableTextEditExtension="true"`는 유지합니다.
- 주피디아 팝업·툴팁 8곳의 ‘동물원 백과사전’을 ‘주피디아’로 통일하고 조사를 수정했습니다.
- 기본 게임·공식 확장팩 목차 60개와 공식 다운로드 팩 목차 9개를 전용 목차 경로로 묶었습니다. 루트는 하나로 유지하고 시작 안내를 맨 위에, 나머지는 각 분류 안에서 한글 제목 기준 가나다순으로 정렬합니다. 항목 ID·링크·분류 관계·버전 조건은 유지합니다.
- 상단 ‘주피디아’ 제목을 금색 탭 안에서 가운데로 배치했습니다.
- 동물 페이지의 사실 제목 177곳을 ‘동물 이름에 대한’ / ‘재밌는 사실’로 나누어 명시적인 줄바꿈을 넣었습니다. 동물 설명 본문은 유지합니다.
- 기본판의 입력창 등 남은 글꼴 설정도 굴림으로 통일했습니다.

**목차는 기본 게임과 현재 포함한 공식 팩 기준입니다. 다른 모드가 추가하는 목차 XML은 자동으로 포함하지 않습니다.** Radical Remake나 다른 UI 모드와 함께 사용하는 경우 별도 호환 작업이 필요할 수 있습니다. 모드 자체와 전용 호환 패치는 이 배포에 포함하지 않습니다.

## 번역 기준과 출처

기존 한글판의 표현을 바탕으로 같은 동물·시설의 이름을 제목·툴팁·본문·사진 목표·기념품에서 맞춥니다. 주피디아·관람객·우리·동물원 명성 등의 용어를 통일하고, 자유 울타리 모드와 자유 게임 모드를 구별합니다. 제품 이름은 영어 고유명사로 유지합니다. 신생대 시대 이름은 팔레오세·에오세·올리고세·마이오세·플라이오세·플라이스토세·홀로세를 사용합니다. 상세 기준과 과학 교정 출처는 [TERMINOLOGY.md](TERMINOLOGY.md)를 참고하십시오.

주피디아 일반 본문은 크기 10, 본문·학명·링크 색은 #3C3626입니다. 링크 동작과 보존 상태 색은 유지합니다. 이 색은 기본 게임의 밝은 배경용입니다.

- 기존 번역과 배포: [hijae/ZT2KorLang](https://github.com/hijae/ZT2KorLang).
- 초기 한국어 작업: **GaMERCaT**. [원 카페 글](https://cafe.naver.com/newzootycooncafe/187)의 기여를 존중합니다.
- 글꼴: [Gulim — Microsoft](https://learn.microsoft.com/en-us/typography/font-list/gulim), [Pretendard — orioncactus](https://github.com/orioncactus/pretendard).
- **AI 사용:** Codex를 이용해 XML 수정·표현 검토·빌드·자동 검사를 진행했습니다. 아래에 명시한 게임 화면은 사용자가 확인했습니다.

게임 내 저작권·상표 고지와 기존 번역자의 기여를 유지합니다. 이 문서는 이용 조건을 새로 정하지 않습니다.

## 빌드와 검증

Python 표준 라이브러리로 빌드하며, `Korean` 폴더에서 실행합니다.

```text
python build_patch.py --check
python build_patch.py
python build_patch.py --font pretendard
python -m unittest discover -v
```

`--date YYYY-MM-DD`로 파일명 날짜를 지정할 수 있습니다. 기본 날짜는 2026-10-10입니다. 워크플로는 두 글꼴판을 빌드해 같은 릴리즈에 등록합니다.

검토 소스는 언어 XML 332개·UI XML 97개·설정 XML 2개, 총 431개입니다. 기존 저장소 XML과 합친 통합본은 485개 항목을 포함합니다. 매니페스트의 해시·XML 구문·ID·형식 토큰·참조·구조를 검증하며, 기존 소스는 LF로 정규화해 비교합니다. Pretendard 선택은 허용된 글꼴 속성만 바꿉니다. 빌드 산출물에는 문서·검사 스크립트를 넣지 않습니다.

자동 검사 16개는 글꼴 분리, 기존 파일 병합, 글꼴 확대 설정, 목차 루트·다운로드 항목 일관성, 두 줄 제목, 제목 위치, 팝업 용어, XML·경로·ID·토큰·참조·해시 변조 거부를 확인합니다. 두 판의 ZIP CRC와 내용, 글꼴 외 내용 일치, 반복 빌드의 재현성도 검사했습니다. 상세 결과와 SHA256은 [validation_summary.json](validation_summary.json)에 기록합니다.

사용자는 프리텐다드 선명도 개선을 확인했고, 화면으로 목차가 하나로 합쳐진 상태와 제목의 좌우 가운데 정렬을 확인했습니다. 이후의 상하 위치와 두 줄 제목, 굴림판 최종 렌더링은 별도 화면 확인이 남아 있습니다. 모든 페이지의 줄바꿈·스크롤, 캠페인 전체, 저장·불러오기나 다른 PC의 실행을 검증했다고 주장하지 않습니다.

기존 `lang/1033/aa_entity_foliage_rr.xml`의 구문 오류는 원본 그대로 포함되며 이번 수정 대상이 아닙니다. 과거 로컬 실행 파일 변경은 이 XML 배포에 포함하지 않습니다.
