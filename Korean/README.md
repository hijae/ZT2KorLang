# 주타이쿤 2 한국어 패치 — 2026-10-11

기존 번역을 보완한 통합 XML 패치입니다. 기본판은 굴림(Gulim), 선택판은 Pretendard를 사용하며 두 판의 문구·배치는 같으며 굴림판에만 제한된 메뉴 굵기 보정을 적용합니다. 실행 파일·DLL·TTF·이미지·저장 게임·개인 설정은 배포하지 않습니다.

## 이번 변경

- 메뉴와 패널 글자가 고해상도에서 축소되는 문제를 완화하도록 `MaxFontScalingResolution`을 600에서 20000으로 복원했습니다. 그 밖의 로케일 설정과 `disableTextEditExtension="true"`는 유지합니다.
- 주피디아 팝업·툴팁 8곳의 ‘동물원 백과사전’을 ‘주피디아’로 통일하고 조사를 수정했습니다.
- 기본 게임·공식 확장팩 목차 60개와 공식 다운로드 팩 목차 9개를 전용 목차 경로로 묶었습니다. 루트는 하나로 유지하고 시작 안내를 맨 위에, 나머지는 각 분류 안에서 한글 제목 기준 가나다순으로 정렬합니다. 항목 ID·링크·분류 관계·버전 조건은 유지합니다.
- 상단 ‘주피디아’ 제목을 금색 탭 안에서 가운데로 배치했습니다.
- 동물 페이지의 사실 제목 177곳을 ‘동물 이름에 대한’ / ‘재밌는 사실’로 나누어 명시적인 줄바꿈을 넣었습니다. 동물 설명 본문은 유지합니다.
- 기본판의 입력창 등 남은 글꼴 설정도 굴림으로 통일했습니다.
- 기존 lang/config 패치를 원래 파일명으로 별도 생성합니다. 보완판은 Complete-Gulim / Complete-Pretendard 이름으로 구분합니다.
- 굴림판은 패키지의 BFFont와 ui.xml/*_ui.xml의 일반 font 내용을 빌드 단계에서 굵게 처리합니다. 기존 강조가 있거나 동적 서식 토큰을 포함한 font는 그대로 유지하여 추가 중첩을 피합니다. Pretendard판에는 이 굵기 변환을 적용하지 않습니다.

**굵기 보정은 전체 게임 UI나 모든 본문을 포괄하지 않습니다.** 패키지 밖 UI, 주피디아 본문, 기존 부분 강조 및 동적 서식은 기존 굵기가 남을 수 있습니다. 검증하지 않은 게임 리소스를 추가로 덮어쓰지는 않습니다.

**목차는 기본 게임과 현재 포함한 공식 팩 기준입니다. 다른 모드가 추가하는 목차 XML은 자동으로 포함하지 않습니다.** Radical Remake나 다른 UI 모드와 함께 사용하는 경우 별도 호환 작업이 필요할 수 있습니다. 모드 자체와 전용 호환 패치는 이 배포에 포함하지 않습니다.

## 번역 기준과 출처

기존 한글판의 표현을 바탕으로 같은 동물·시설의 이름을 제목·툴팁·본문·사진 목표·기념품에서 맞춥니다. 주피디아·관람객·우리·동물원 명성 등의 용어를 통일하고, 자유 울타리 모드와 자유 게임 모드를 구별합니다. 제품 이름은 영어 고유명사로 유지합니다. 신생대 시대 이름은 팔레오세·에오세·올리고세·마이오세·플라이오세·플라이스토세·홀로세를 사용합니다. 상세 기준과 과학 교정 출처는 [TERMINOLOGY.md](TERMINOLOGY.md)를 참고하십시오.

주피디아 일반 본문은 크기 10, 본문·학명·링크 색은 #3C3626입니다. 링크 동작과 보존 상태 색은 유지합니다. 이 색은 기본 게임의 밝은 배경용입니다.

## 빌드와 검증

Python 표준 라이브러리로 빌드하며, `Korean` 폴더에서 실행합니다.

```text
python build_patch.py --check
python build_patch.py --edition legacy
python build_patch.py
python build_patch.py --font pretendard
python -m unittest discover -v
```

`--date YYYY-MM-DD`로 파일명 날짜를 지정할 수 있습니다. 기본 날짜는 2026-10-11입니다. 워크플로는 기존판 빌드·릴리즈와 보완판 검사·빌드를 독립된 job으로 실행합니다. 보완판 테스트나 빌드가 실패해도 기존판은 자체 빌드·업로드가 성공하면 릴리즈됩니다. 보완판 두 글꼴판은 검사가 모두 성공한 경우에만 기존판 릴리즈에 추가되며 기존 첨부 파일은 유지됩니다. 보완판 검사·빌드 실패 시 로그와 실행 요약에 `lang 변경됨, 매니페스트 갱신 필요`를 표시합니다. 이 문구는 점검 안내이며 실제 실패 원인은 해당 로그로 확인해야 합니다. 보완판 릴리즈 업로드 오류에도 같은 점검 문구와 업로드 실패 안내를 표시합니다. main에 병합되어 워크플로가 실행되기 전에는 릴리즈가 생성되지 않습니다.

검토 소스는 언어 XML 332개·UI XML 97개·설정 XML 2개, 총 431개입니다. 기존 저장소 XML과 합친 통합본은 485개 항목을 포함합니다. 매니페스트의 해시·XML 구문·ID·형식 토큰·참조·구조를 검증하며, 기존 소스는 LF로 정규화해 비교합니다. Pretendard 선택은 허용된 글꼴 속성만 바꾸고, 굴림 선택은 검증 후 제한된 굵기 변환을 추가로 수행합니다. 기존판은 매니페스트 검증을 건너뛰고 현재 lang/config 아래의 일반 파일을 경로 안전 검사 후 바이트 그대로 묶습니다. 파일 개수·해시를 고정하지 않고 XML 구문 검사·글꼴 변환·줄바꿈 정규화도 하지 않습니다. 보완판의 소스·기존 XML 해시 고정은 유지합니다. 빌드 산출물에는 문서·검사 스크립트를 넣지 않습니다.

자동 검사 22개는 기존 검증에 더해 배포 분리, 기존판 내용 보존·매니페스트 독립 빌드·파일 추가/삭제/수정 허용·링크 거부, 굵기 변환의 범위·반복 안정성·중첩 회피를 확인합니다. 세 산출물의 CRC·파일 내용·반복 빌드 재현성을 별도로 확인합니다. 자세한 결과는 [validation_summary.json](validation_summary.json)에 기록합니다.

사용자는 이전 프리텐다드 선명도 개선, 목차 단일화와 제목 좌우 정렬을 확인했습니다. 굴림 시험본의 굵기는 괜찮아 보인다고 보고했습니다. 이번 빌드에서는 기존 강조·동적 서식을 보존하는 방식으로 바꿨으므로, **이 최종 산출물의 실제 화면 확인은 아직 남아 있습니다.** 사용자는 여러 해상도에서 얇음이 비슷했다고 보고했으며, 모든 저해상도 화면에서 잘림이 없다는 검증을 완료한 것은 아닙니다.

남은 확인 대상은 동물 정보·메인 메뉴·하단 패널·확인창·주피디아 본문, 돈·상태 숫자, 긴 툴팁과 800×600/1024×768의 잘림입니다. 모든 페이지·캠페인·저장/불러오기·다른 PC의 실행을 검증했다고 주장하지 않습니다.

기존 `lang/1033/aa_entity_foliage_rr.xml`의 구문 오류는 원본 그대로 포함되며 이번 수정 대상이 아닙니다. 기존판에는 원 소스의 `speciessurvival_entries_cp2_edits.xml` 중복 속성 오류도 그대로 남습니다. 보완판은 해당 파일을 검증된 보완 소스로 대체하므로 이 두 번째 오류가 없습니다. 과거 로컬 실행 파일 변경은 이 XML 배포에 포함하지 않습니다.

- 1024×768에서 긴 주피디아 제목이 불필요하게 줄바꿈되지 않도록 재미있는 사실 제목 칸을 176에서 236으로 넓혔습니다. 300 폭의 기존 열 안에서 아이콘 64와 제목 236을 배치합니다.

- 기존 공통 레이아웃을 조정했으며 자동 화면 비율 감지 기능은 추가하지 않았습니다. 사용자가 로컬 수정본을 확인하고 수용했으나, 모든 페이지를 4:3과 16:9에서 전수 검증한 것은 아닙니다.
