# 주타이쿤 2 한국어 번역 보완 패키지

[hijae/ZT2KorLang](https://github.com/hijae/ZT2KorLang)의 번역을 바탕으로 본편·공식 확장팩·공식 다운로드 문구를 보완한 모듈입니다. 기존 번역자의 표현과 합니다체·하세요형을 따르며 등장인물의 혼잣말은 기존 말투를 유지합니다. 원래 저장소의 `lang`·`config` 파일은 변경하지 않고, 빌드할 때 기존 XML에 보완 XML을 합쳐 한 파일로 배포합니다.

## 범위

- 본편, **Endangered Species**, **African Adventure**, **Marine Mania**, **Extinct Animals**, **Dino Danger Pack** 및 확인한 공식 다운로드 9개 팩을 다룹니다. 제품 이름은 영어 고유명사로 유지합니다.
- 공식 콘텐츠 소스 314개에 기존 번역의 글꼴 보완용 45개를 더하여 **359개 XML**입니다. 언어 XML 332개, UI XML 26개, IME 글꼴 설정 1개이며 `LOC_STRING`은 **17,141개**입니다. 목록·해시·검증값은 [manifest.json](manifest.json)에 있습니다.
- 배포 파일에는 기존 XML 364개와 보완 XML 359개를 경로별로 합친 **414개 XML**이 들어갑니다. 보완 XML이 같은 경로의 기존 XML을 대체하며, 보완 대상 밖의 기존 XML 55개는 보존합니다. 기존 파일 해시는 줄바꿈을 LF로 정규화해 검증하므로 Windows와 Linux에서 같은 파일을 생성합니다.
- 추가 45개는 기존 저장소의 공식·비공식 번역을 복사하여 글꼴 설정만 보완한 파일입니다. 원래 문장·ID·이미지·표 좌표·기능 값은 유지합니다. 비공식 주피디아의 글꼴 태그 밖 본문에도 글꼴을 지정하되, 표나 셀 전체를 글꼴 태그로 감싸지 않습니다. 이 파일들에 원래 남아 있던 영어·네덜란드어를 새로 번역했다는 뜻은 아닙니다.
- 모든 외부 모드와 나중에 추가한 번역 파일까지 자동으로 통일하지는 않습니다. 같은 XML을 나중에 덮어쓰는 모드가 있으면 표시가 달라질 수 있습니다.
- 실행 파일·DLL·TTF·이미지·저장 게임·개인 설정은 포함하지 않습니다. Radical Remake 자체와 해당 모드 전용 호환 파일도 포함하지 않습니다.

## 번역 기준

같은 동물·시설의 이름을 제목·툴팁·본문·사진 목표·기념품에서 맞춥니다. 주피디아, 관람객, 우리, 동물원 명성, 화석 탐지·조립·질병 치료와 공룡 마취 모드 등의 용어를 통일했습니다. 자유 울타리 모드와 자유 게임 모드, 수조 건설과 건물, 은신처와 우리는 구별합니다.

이전 원문 대조에서 교정한 2,217개 문구와 용어 통일 157개 필드를 유지합니다. 이번 검토에서는 제품 필터·설치 알림·튜토리얼·제품 및 상표 고지 등의 **71개 text/tail 필드**에 영어 확장팩 이름을 복원했습니다. 일반 문장의 "위험한 공룡", "멸종 동물 연구소", "해양 동물" 등은 제품 이름과 구별하여 한국어로 유지합니다. 영어 제품 이름 뒤 조사도 문맥에 맞춥니다.

신생대 시대 이름은 팔레오세·에오세·올리고세·마이오세·플라이오세·플라이스토세·홀로세로 맞춥니다. 학명과 원문 측정 단위, 키·경로·파일 형식·URL·리소스 참조와 형식 토큰은 용도에 맞게 보존합니다. 저장·임시 폴더의 기능 값은 원래 `Saved`·`tmp`입니다. 상세 사례·팩 목록·과학 교정 출처는 [TERMINOLOGY.md](TERMINOLOGY.md)를 확인하십시오.

주피디아 일반 본문은 크기 10, 본문·학명·링크 글자색은 **#3C3626**입니다. 링크 대상·클릭 동작과 보존 상태의 구분 색은 유지합니다. 기존에 검토한 분류표·학명은 보통체로 표시하며 일반 강조는 유지합니다. 이 색은 기본 게임의 밝은 주피디아 배경용입니다. 검은 배경의 외부 UI 모드에는 별도의 호환 처리가 필요합니다.

## 글꼴 선택

배포 기본판은 기존 한국어 패치의 **Gulim(굴림)**을 사용합니다. 유지관리자의 요청에 따라 기본 글꼴을 보존하며 Pretendard의 설치나 자동 대체에 의존하지 않습니다. 변경된 공식 번역과 기존 비공식 번역에 동일한 글꼴을 지정합니다. 글꼴 정보는 Microsoft의 [Gulim 문서](https://learn.microsoft.com/en-us/typography/font-list/gulim)를 참고하십시오.

**Pretendard 선택판**도 같은 소스로 빌드합니다. 공식 [Pretendard](https://github.com/orioncactus/pretendard)의 정적 TTF Regular·Bold를 Windows에 설치하고 게임을 다시 실행한 뒤 사용하십시오. 글꼴 파일을 재배포하거나 설치하지 않습니다. Pretendard가 없으면 선택판을 사용하지 말고 기본판을 선택하십시오. 자동 대체 글꼴의 모양과 글자 폭은 보장하지 않습니다.

| 판 | 보충 패치 파일 | 별도 글꼴 설치 |
|---|---|---|
| 기본 | `ZZZZZZKorlang2026-10-08.z2f` | 기존 한국어 패치의 굴림 사용 |
| 선택 | `ZZZZZZKorlang2026-10-08-Pretendard.z2f` | Pretendard 정적 Regular·Bold 필요 |

**두 배포 파일 중 하나만 설치하십시오.** 기본판은 원 저장소와 같은 `ZZZZZZKorlang[YYYY-MM-DD].z2f` 형식입니다. 이전 날짜의 한국어 패치와 이전 보충 파일은 백업 후 설치 폴더에서 제거하십시오. 두 판이나 이전 판을 함께 설치하여 파일명 순서에 맡기지 않습니다.

## 빌드와 검사

Python 3.9 이상과 표준 라이브러리만 필요합니다. `complete-korean`에서 실행하십시오.

```text
python build_patch.py --check
python build_patch.py
python build_patch.py --font pretendard
python -m unittest discover -v
```

빌더는 매니페스트에 등록된 소스의 해시·XML 구문·ID·형식 토큰·참조·태그·속성을 확인합니다. Pretendard 선택판은 검증 후 **글꼴 속성만** 바꾸며, 문구·ID·배치·리소스 참조는 기본판과 동일합니다. 원본 `UI`·`ui` 경로의 대소문자는 매니페스트의 `path`에 유지하고 작업 소스는 `source_path`로 구분합니다. 소스 수정 시 검토 후 매니페스트도 갱신해야 하며 빌더가 임의로 다시 승인하지 않습니다. 기존 XML 364개의 파일 목록과 LF 기준 해시도 매니페스트에 등록되어 있습니다.

릴리스 워크플로는 기존 번역과 보완 내용을 합친 기본판·Pretendard 선택판 두 파일을 생성합니다. `--date YYYY-MM-DD`로 파일명에 넣을 릴리스 날짜를 지정하며, 지정하지 않으면 이번 검토 날짜인 2026-10-08을 사용합니다. ZIP에는 등록된 XML만 포함하며 문서·검증 스크립트는 넣지 않습니다.

Windows에서는 선택되는 실제 글꼴을 다음과 같이 확인할 수 있습니다.

```text
python font_probe.py --font system --missing-font-control
python font_probe.py --font pretendard
```

이 검사는 메모리 DC에서 `CreateFontW`·`GetTextFaceW`·`GetGlyphIndicesW`를 사용합니다. 글꼴 등록·삭제, 시스템 설정 변경이나 게임 조작을 하지 않습니다. 선택한 글꼴이 실제로 대체되었거나 검사한 글자가 누락되면 실패합니다. 시험용 미설치 글꼴 이름의 결과는 그 PC의 대체 동작을 기록할 뿐, Pretendard를 제거한 별도 PC의 실행 시험으로 간주하지 않습니다.

## 설치·제거

1. 게임을 종료합니다. Pretendard 선택판을 쓰는 경우 해당 글꼴을 준비합니다.
2. 이전 한국어 패치·보충 패치를 백업 후 설치 폴더에서 제거하고, 선택한 **배포 파일 하나**를 `zt.exe`가 있는 폴더에 넣습니다. 압축을 풀거나 파일명을 바꾸지 않습니다.
3. 게임을 다시 실행하여 메뉴·주피디아·튜토리얼과 사용하는 공식·비공식 콘텐츠를 확인합니다.
4. 판을 바꾸거나 제거하려면 이전 한국어 패치 `.z2f`를 먼저 제거하십시오. 게임이나 글꼴 파일을 수정할 필요는 없습니다.

## 검증 상태와 한계

2026-10-08의 [validation_summary.json](validation_summary.json)에 두 빌드의 SHA256과 검증 범위를 기록합니다. 보완 소스 359개 XML의 구문·매니페스트와 통합 배포 414개 항목의 CRC·내용을 검사했습니다. 기본판과 Pretendard 판의 글꼴 외 내용도 대조했습니다. 기존 45개 파일의 문구·기존 스타일 속성·배치·참조를 대조했고, 공식 소스는 승인한 제품명 71개 필드 외에 ID·형식 토큰·참조를 유지합니다. 반복 빌드 결과는 동일합니다.

자동 검사 13개는 두 글꼴판의 범위·내용 일치, 기존 명시적 글꼴 파일의 포함, 제품명과 일반 문장의 구분, XML 오류·미등록 파일·경로 이탈·ID·형식 토큰·참조 변조 거부와 기존 파일 병합·해시 변조 거부·릴리스 파일명 규칙을 확인합니다. Windows GDI 검사에서는 기본·선택 글꼴의 보통·굵은 글꼴 요청과 소스에 사용된 한글·ASCII **1,351자**에 누락이 없었습니다. 미설치 시험 이름에는 이 환경에서 굴림이 선택되어 자동 대체가 원하는 글꼴과 같다는 보장을 할 수 없음을 확인했습니다.

원 저장소의 구문 오류 2개 중 보완 파일로 대체되지 않는 `lang/1033/aa_entity_foliage_rr.xml` 1개는 기존 내용으로 포함합니다. 이 파일의 구문 오류를 이번 작업에서 고쳤다고 주장하지 않습니다.

**이번 수정본의 게임 화면, Pretendard가 없는 별도 PC에서의 실제 게임 실행, 모든 페이지의 줄바꿈·스크롤, 캠페인 전체와 저장·불러오기는 미검증입니다.** GDI 검사와 XML 정적 검증을 실제 게임 시험으로 표현하지 않습니다.

이전 `188dcc` 버전에서 사용자가 확인한 판다 학명·대형 화장실 툴팁 결과는 과거 버전에 한정됩니다. 그 확인 환경에는 Arial을 Pretendard로 바꾼 별도의 로컬 실행 파일 변경도 있었습니다. 실행 파일과 TTF는 공개 패키지에 포함하지 않으며 XML 패치만으로 실행 파일에 직접 들어 있는 모든 글꼴명을 교체했다고 주장하지 않습니다.
