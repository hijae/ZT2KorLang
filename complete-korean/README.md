# 주타이쿤 2 한국어 번역 보충 패키지

[hijae/ZT2KorLang](https://github.com/hijae/ZT2KorLang)의 기존 한국어 번역을 바탕으로 본편·공식 확장팩·공식 다운로드의 문구를 보완한 별도 모듈입니다. 메뉴와 조작 안내, 동물·시설 이름, 주피디아, 튜토리얼, 캠페인·챌린지·사진 과제·포상의 원문을 다시 대조했습니다. 기존 번역자의 표현과 합니다체·하세요형을 따르며 등장인물의 혼잣말은 기존 말투를 유지합니다.

기존 저장소의 번역 파일을 삭제하거나 교체하지 않습니다. 기존 패치의 비공식 모드 번역을 유지하면서 `complete-korean`만 따로 검토·빌드할 수 있습니다. 모든 외부 모드의 추가 문구가 번역 범위에 포함되는 것은 아닙니다.

## 범위와 현재 버전

- 본편, 멸종 위기 동물, 아프리카 대탐험, 해양 동물, 멸종 동물, 위험한 공룡 팩과 확인한 공식 다운로드 9개 팩을 다룹니다.
- 언어 XML **287개**, UI XML **26개**, `config/imeui.xml` **1개**, 총 **314개 XML**입니다. `LOC_STRING`은 **15,449개**이며 파일별 내용과 검증값은 [manifest.json](manifest.json)에 있습니다.
- 공식 다운로드의 언어 XML 10개를 포함합니다. 팩 목록과 용어·과학 출처는 [TERMINOLOGY.md](TERMINOLOGY.md)에 정리했습니다.
- 표시 문구와 필수 영문 식별자를 구분하여 검수했습니다. 학명, 원문의 측정 단위, 실제 키·경로·파일 형식·URL·리소스 참조, `null`과 실행 형식 토큰은 용도에 맞게 보존합니다. 근거가 확인된 원전 학명 철자와 시대 오류는 별도 교정으로 명시합니다.
- 게임 실행 파일·DLL·이미지·스크립트·글꼴 파일·저장 게임·개인 설정·계정 정보·진단 로그는 포함하지 않습니다. `config/imeui.xml`은 게임 리소스의 글꼴명 설정 XML입니다.

이번 원문 대조에서 언어 XML 186개에 걸친 승인된 문구 **2,217개**를 교정했습니다. 최종 표시 용어 통일은 157개 필드에 적용했습니다. 이 수는 이전 단계의 수정 수와 단순 합산하지 않습니다.

## 수정 기준과 주요 사례

- 같은 객체의 이름을 제목·툴팁·본문·사진 목표·기념품에서 맞춥니다. 주피디아, 관람객, 우리, 동물원 명성, 화석 탐지·화석 조립·질병 치료와 공룡 마취 모드 등의 표기를 통일했습니다.
- 자유 울타리 모드와 자유 게임 모드, 수조 건설과 건물, 은신처와 우리를 구별합니다. 마우스 클릭·이동·회전과 종료 안내를 실제 도구 문맥에 맞췄습니다.
- 영어에서 빠졌거나 잘못 바뀐 목표 개수, 수유 주체, 동물의 행동, 관람과 사진 촬영의 차이, 공연 등급과 동물원 명성의 차이를 복원했습니다. 시설의 가격·판매 품목·테마 효과 등 원문이 실제로 다른 기능은 구분합니다.
- 아크릴 유리 울타리, 대형·소형 콘크리트 은신처, 멸종 동물 벤치·기념품 가판대 등 같은 시설의 이름을 맞췄습니다. 단계별 포상은 순위로 오해하지 않도록 1·2·3단계상으로 표시합니다.
- 신생대 시대 이름은 팔레오세·에오세·올리고세·마이오세·플라이오세·플라이스토세·홀로세로 통일합니다. 시대 표기 통일과 과학 원문의 별도 오류 교정은 구분합니다.
- 저장·임시 폴더의 기능 값은 원래 `Saved`·`tmp`를 유지합니다. 실행 형식 토큰의 값과 개수는 보존하며, 수유 문장 한 곳은 원전의 주체·대상에 맞게 `%2s`·`%1s` 순서를 복구했습니다.

주피디아 본문 779곳은 문자 조각마다 Pretendard 크기 10과 지정된 본문색을 명시합니다. 승인된 주피디아 본문·학명·링크 글자색을 검정에 가까운 색보다 조금 연한 짙은 회갈색 **#3C3626**로 맞춥니다. 색상 노드 3,550곳의 RGB 속성 10,650개 변경을 별도로 승인·대조했으며 링크 대상·클릭 동작과 보존 상태의 구분 색은 유지합니다. 표·셀 전체를 글꼴 태그로 감싸지 않으며 링크·이미지·좌표를 유지합니다. 분류표 177곳의 강·목·과·속·종·아종과 확인한 본문 학명은 보통체로 표시하고 일반 강조는 유지합니다. 제목 177곳은 **재미있는 사실**로 줄였으며 기존 크기 12와 레이아웃 속성은 유지합니다. 옵션·게임 중 옵션의 추가 UI XML 두 개는 Comic Sans MS 글꼴명만 Pretendard로 바꾸고 원래 내용과 배치를 보존합니다.

## 글꼴과 빌드

[Pretendard 공식 저장소](https://github.com/orioncactus/pretendard)의 정적 TTF **Pretendard Regular**와 **Pretendard Bold**를 Windows의 모든 사용자용으로 설치하고 게임을 다시 실행하십시오. 글꼴 파일은 재배포하지 않습니다.

Python 3.9 이상과 표준 라이브러리만 필요합니다. `complete-korean`에서 실행하십시오.

```text
python build_patch.py --check
python build_patch.py
```

같은 폴더에 `ZZZZZZZZ_Korlang_Complete_20261007.z2f`를 생성합니다. 빌더는 매니페스트에 등록된 314개 XML의 파일 해시·XML 구문·ID·형식 토큰·참조·태그·속성을 확인하며 문서나 개인 파일을 압축하지 않습니다. 게임 폴더와 네트워크에는 접근하지 않습니다. 소스를 수정한 경우 검토 후 매니페스트도 갱신해야 하며 빌더가 임의로 다시 승인하지 않습니다.

원본 리소스의 `UI`·`ui` 대소문자는 매니페스트의 `path`에 유지합니다. 작업용 `source`는 `source_path`로 구분하므로 Windows에서 같은 폴더를 둘로 만들 필요가 없습니다.

이 기여안의 [릴리스 워크플로](../.github/workflows/main.yml)는 기존 패치에는 원래의 `lang`·`config` 리소스만 압축하고, 보충 빌더로 생성한 `.z2f`를 같은 릴리스의 두 번째 파일로 첨부합니다. 기존 패치 이름과 원 저장소의 번역은 유지합니다. 수동 빌드에는 위 명령을 사용할 수 있습니다.

## 설치와 제거

1. 게임을 종료하고 위의 Pretendard 글꼴을 준비합니다.
2. 생성한 `ZZZZZZZZ_Korlang_Complete_20261007.z2f`를 `zt.exe`가 있는 설치 폴더에 넣습니다. 압축을 풀지 않습니다.
3. 기존 `ZZZZZZKorlang[날짜].z2f`를 함께 유지하면 기존 비공식 모드 번역을 사용할 수 있습니다. 새 파일은 `Z`가 8개로 기존 6개 파일보다 뒤에 적용됩니다. 파일명을 유지하십시오.
4. 게임을 실행하여 메뉴·주피디아·튜토리얼과 사용하는 공식 다운로드 문구를 확인합니다.

같은 XML을 더 나중에 덮어쓰는 모드가 있으면 문구가 달라질 수 있습니다. 제거하려면 이 보충 `.z2f`만 삭제합니다.

## 검증 상태와 한계

2026-10-08 새 검토 후보의 SHA256은 `a25c2953174225b7dd00ffb4f8850e101fd40c07f2bfe28255a4b26108431171`입니다. 공개 소스 재빌드의 SHA256이 이 후보와 같은 것을 확인했습니다. 잘못된 XML·미등록 파일·경로 이탈·ID·형식 토큰·참조 변조에 대한 6개의 거부 검사를 통과했습니다. 최종 상태는 [validation_summary.json](validation_summary.json)에 기록합니다.

독립 검사는 승인된 2,217개 실제 text/tail 변경과 UI 두 개의 글꼴명 변경·승인된 주피디아 RGB 색상 속성을 대조했습니다. 이 승인된 변경을 제외한 기존 태그·속성·ID·리소스 참조·표 좌표·이미지와 기능 값은 보존하며, 형식 토큰 순서는 원문 수유 문장의 역할 복구 한 곳만 예외로 검증했습니다. 미번역 영어·제어 문자와 오래된 표시 용어도 정적으로 확인합니다. 정적 검사와 문장 대조는 실제 캠페인 완료나 화면 배치 검증과 다릅니다.

새 후보와 로컬 설치 파일의 SHA256 일치를 확인했습니다. **새 후보의 화면 표시와 실제 플레이 동작은 아직 확인 전입니다.** 저장·불러오기, 모든 페이지·캠페인 목표, 제목 줄바꿈과 전체 모드 조합은 미검증입니다.

이전 `188dcc` 버전에서는 사용자가 재실행 후 **판다 학명이 선명하고 기본·툰드라 대형 화장실 설명이 같다**고 확인했습니다. 이 두 항목에 한정된 확인이며 새 후보의 실행 검증으로 옮기지 않습니다. 그 이전 판다·안킬로사우루스 두 화면에서는 보이는 일반 본문의 대비 개선을 확인했고 확대된 기울임 학명의 윤곽 문제는 보통체 변경의 근거로 남겼습니다.

이전 화면 확인 환경에는 기본 Arial을 Pretendard로 바꾼 별도의 로컬 실행 파일 변경이 있었습니다. 그 실행 파일과 TTF는 공개 패키지에 포함하지 않습니다. 실행 파일에 직접 들어 있는 글꼴명은 XML 패치만으로 해결했다고 주장하지 않습니다.
